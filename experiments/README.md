# Experimentos históricos

Estos archivos conservan las primeras audiciones: tres timbres, R, ERRE y primeros cierres emocionales. No son la implementación vigente. Algunas muestras usan tiempos anteriores y R/ERRE, retirados después en favor de OK y ERR.

Para toda ejecución actual, usar `scripts/robot-voice.ps1` en Windows o `scripts/speak.sh` en macOS, Linux y WSL. La habilidad de portapapeles usa `robot-voice.ps1`. Los experimentos se incluyen para documentar la evolución, no para crear fuentes paralelas del protocolo.
